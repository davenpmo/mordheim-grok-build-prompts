# Mordheim: City of the Damned — Grok Build Prompts

Rules-first prompt series for a 1999-rules 3D isometric Mordheim skirmish (Vite + React + TS + Three.js).

## Files

- `mordheim-grok-build-prompts.ipynb` — open this in Jupyter, VS Code, Cursor, or Colab. Each prompt is its own markdown cell.
- `mordheim-grok-build-prompts.md` — same content as a single markdown file.

## How to use

1. Download the `.ipynb`.
2. Open it in any notebook app.
3. Copy **one cell** into Grok Build Mode.
4. Start at **Prompt 00**. Do not start at the art prompt.
5. Play after each prompt. Art is Prompt 08.

Locked stack: Vite + React + TypeScript + Three.js + OrthographicCamera. 1 world unit = 1 inch. Persist key `mordheim.campaign.v1`. Slice = Reikland Mercenaries vs Witch Hunters.
