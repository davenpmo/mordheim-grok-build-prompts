# Mordheim: City of the Damned — Grok Build Prompt Series

Paste **one numbered prompt at a time** into Grok **Build Mode**.

Do not paste the whole file. Do not start at Prompt 07. Rules first, art last.

A copy lives here so you can iterate without hunting chat history.

Locked for this series:

- Title: **Mordheim: City of the Damned**
- Slice: one **Skirmish** — Reikland Mercenaries vs Witch Hunters
- Stack: Vite + React + TypeScript + Three.js + `OrthographicCamera`
- Scale: **1 world unit = 1 inch** of the 1999 tabletop
- Persist key: `mordheim.campaign.v1`
- Art is Prompt 08. Do not spend tokens on textures, sprites, or lighting until the game plays.

---

## How to use this file

1. Open Grok Build Mode.
2. Paste Prompt 00. Let it finish. Play one grey-capsule game.
3. If inches or the save key are wrong, paste Prompt 01. Otherwise skip it.
4. Paste 02 → 03 → 04 → 05 → 06 → 07 in order. Play after each one.
5. Only then paste 08.
6. Follow-ups are optional and one at a time.

Companion notebook: `mordheim-grok-build-prompts.ipynb` (same repo). Open that in Jupyter / VS Code / Cursor / Colab — each prompt is its own cell.
